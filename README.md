# time_series_recent_report

时间序列预测方向的近期综述文献，以及一份 Haystack 教程。

## 内容

- [`TimeSeries_Reviews_2026/`](TimeSeries_Reviews_2026/)：50 篇 2025–2026 年的综述和基准论文，按领域分为 6 类。入口是 `INDEX.html`，说明见 [`README_zh.md`](TimeSeries_Reviews_2026/README_zh.md)。其中 35 篇是 PDF，15 篇是指向来源的同名 `.url` 文件。
- `haystack-tutorials-main.zip`：[deepset-ai/haystack-tutorials](https://github.com/deepset-ai/haystack-tutorials) 的教程快照（提交 `d451fc0`），Apache-2.0 许可。

论文版权归作者和出版方所有，各篇的许可见 `TimeSeries_Reviews_2026/catalog.csv`。
